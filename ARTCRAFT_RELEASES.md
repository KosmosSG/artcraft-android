# ArtCraft Android Suite — Download Centre

Browse the [ArtCraft download centre](docs/index.html) (source file) or the [GitHub Releases page](https://github.com/KosmosSG/artcraft-android/releases).

The standalone page at `docs/index.html` groups publicly published stable releases automatically by application, with direct links to each existing APK. To host it as a website, enable GitHub Pages using **Deploy from a branch → main → /docs** after the pull request is reviewed and merged.

**Note:** The website URLs require GitHub Pages to be enabled. GitHub Releases remain the source of truth; this directory does not create, delete, republish or alter any release, tag, APK, signing configuration or Android build workflow. Drafts and prereleases are not listed. The page uses the unauthenticated GitHub API and may temporarily be limited by GitHub rate limits. Release names or tags must contain an unambiguous application name for matching; otherwise an APK filename beginning with the application name is used.

The directory is a read-only browser of public GitHub releases. It does not guarantee that a particular APK is upgrade-compatible with an installed app; package name and signing identity still need to match.
