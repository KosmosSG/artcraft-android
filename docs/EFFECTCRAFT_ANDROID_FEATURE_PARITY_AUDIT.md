# EffectCraft Android feature-parity audit — 2026-11-02

**Scope:** user's requested Android compatibility features, comparing the official-reference *builder* `MostafaXS1/artcraft-android@main` against `KosmosSG/artcraft-android`, focusing on EffectCraft PR #82 (`v0.16.0-android.8` lineage) and stacked draft PR #116 (official upstream `v0.20.0` trial). **This is a source inspection, not proof that any APK passed hardware testing.** Avoid overwriting our customized Android builder with the reference.

**Build gate:** PR #116 run [41393106944](https://github.com/KosmosSG/artcraft-android/actions/runs/41393106944) remains **failed** at native compilation. Official upstream `storytold/egui@6d518fc` expects `winit::WindowEvent::ImeResetCompleted` and `Window::reset_ime_with_request`; our vendored `vendor/winit` lacks these APIs. The official upstream pins `storytold/winit@a517b3846ee8457d84ee4975110bfda6797c44dc`. The reference Android mouse/gesture/backend changes must be carefully rebased onto that pinned fork; merely disabling IME or removing pointer support is not acceptable.

## Priority implementation sequence

1. **Unblock v0.20 compile without regressing input:** rebase Android winit pointer handling onto official pinned fork, preserve IME reset API and test cargo compile.
2. **Feature parity of build/runtime:** restore exact two-finger scroll/pinch and cursor bridge; guard long-press context click; verify keyboard Esc and unsaved D/C/S, SAF import/save, scrolling, density and GPU.
3. **Document persistence:** examine official EffectCraft session/engine recovery APIs, implement and test persistent preferences vs document autosave vs complete session restore separately, with two-way SAF sync and failure safeguards.
4. **Build and device gates:** compile ARM64, validate manifest/package/version/icon/native ABI/temporary cert/hash; install the separate `com.artcraft.effectcraft.v020test` trial APK on HONOR MagicPad 4; record all nine tests as pass/fail.
5. **Release gate:** preserve the separately signed `com.artcraft.effectcraft` production app and original key. No production signing, merge, tag or publication without the owner's separate explicit approval.
